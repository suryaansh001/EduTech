TIER-BASED BEHAVIOR FLOW:
═════════════════════════════════════════════════════════════════════════════

USER MAKES REQUEST
    │
    ├─ Authenticate & get user.tier
    │
    ├─ Call controller
    │
    ├─ createAIService('quiz', user.tier)
    │
    └─ TIER CHECK:
       │
       ├─ Is tier 'free'?
       │  └─ YES → Return NoOpAIService
       │
       ├─ Is tier 'premium'?
       │  ├─ Is 'quiz' feature enabled?
       │  │  ├─ YES → Return cached QuizGenService
       │  │  └─ NO  → Return NoOpAIService
       │  └─ Service not registered?
       │     └─ Return NoOpAIService
       │
       └─ Is tier 'enterprise'?
          └─ YES → Return cached real service

SERVICE LIFECYCLE:
═════════════════════════════════════════════════════════════════════════════

APP STARTUP:
  └─ registerService('quiz', QuizGenService)
  └─ registerService('rag', RAGService)
  └─ initializeServices(['quiz', 'rag'])
     ├─ For each tier (premium, enterprise):
     │  └─ For each service:
     │     ├─ createAIService()
     │     ├─ await service.initialize()
     │     └─ Store in cache
     └─ Return initialization results

RUNTIME REQUEST:
  └─ createAIService('quiz', userTier)
     ├─ Check cache first
     │  ├─ If found → Return cached instance
     │  └─ If not found → Create new instance
     ├─ Check tier features
     │  ├─ If disabled → Return NoOp
     │  └─ If enabled → Return real service
     └─ Cache for next request

APP SHUTDOWN:
  └─ shutdownAllServices()
     └─ For each cached service:
        └─ await service.shutdown()

SERVICE INSTANTIATION EXAMPLE:
═════════════════════════════════════════════════════════════════════════════

// Scenario 1: Free tier user
const service = createAIService('quiz', 'free', {
  logger: myLogger
});
// → Returns: NoOpAIService

await service.generateQuestions('content', 5, 'medium');
// → Returns: {success: false, message: "Quiz Generation is not available..."}


// Scenario 2: Premium tier user
const service = createAIService('quiz', 'premium', {
  logger: myLogger,
  apiKey: process.env.OPENAI_API_KEY,
  model: 'gpt-4'
});
// → Returns: QuizGenerationService (cached if already exists)

await service.generateQuestions('content', 5, 'medium');
// → Returns: {success: true, data: [question1, question2, ...]}


// Scenario 3: Feature disabled (override)
const service = createAIService('quiz', 'premium', {
  featureOverrides: { quizGeneration: false }
});
// → Returns: NoOpAIService (even though premium)


MIGRATION PATH FOR EXISTING SERVICES:
═════════════════════════════════════════════════════════════════════════════

OLD WAY (Direct import):
  import { chatService } from './services/chat.service.js';
  const message = await chatService.sendMessage(...);

NEW WAY (With factory):
  import { createAIService } from './services/ai/index.js';
  const chatService = createAIService('chat', userTier);
  const result = await chatService.sendMessage(...);

MIGRATION OPTIONS:

1. Wrap Existing Service:
   class WrappedChatService extends BaseAIService {
     async sendMessage(...) {
       return this.originalService.sendMessage(...);
     }
   }

2. Full Refactor:
   class NewChatService extends BaseAIService {
     // Full implementation
   }

3. Hybrid:
   Some methods use factory, some use old pattern
   (Gradual migration)

KEY BENEFITS VISUALIZATION:
═════════════════════════════════════════════════════════════════════════════

WITHOUT FACTORY PATTERN:
  Route 1:  if (tier === 'free') → return error
           else if (tier === 'premium') → service.method()
           else if (tier === 'enterprise') → service.method()

  Route 2:  if (tier === 'free') → return error
           else if (tier === 'premium') → service.method()
           else if (tier === 'enterprise') → service.method()

  Route N:  if (tier === 'free') → return error
           else if (tier === 'premium') → service.method()
           else if (tier === 'enterprise') → service.method()

  Result: LOTS OF DUPLICATION ❌


WITH FACTORY PATTERN:
  Factory:  tier → NoOp OR Real service (centralized)

  Route 1:  const service = createAIService(...);
           service.method();

  Route 2:  const service = createAIService(...);
           service.method();

  Route N:  const service = createAIService(...);
           service.method();

  Result: SINGLE CODE PATH ✓


═════════════════════════════════════════════════════════════════════════════
  The factory pattern eliminates code duplication and makes tier-based
  feature access transparent to route handlers!
