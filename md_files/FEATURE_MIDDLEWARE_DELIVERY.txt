1. requireFeature(featureName)
   ├─ Purpose: Enforce single feature access
   ├─ Returns: 402 (free tier), 403 (insufficient tier)
   └─ Example: router.post('/endpoint', authenticate, requireFeature('AI_CHAT'))

2. requireAnyFeature(featureArray)
   ├─ Purpose: OR logic - at least one feature required
   ├─ Returns: 402/403 if none available
   └─ Example: requireAnyFeature(['FEATURE1', 'FEATURE2'])

3. trackFeatureUsage(featureName)
   ├─ Purpose: Track usage without blocking
   ├─ Returns: Always allows request
   └─ Example: trackFeatureUsage('AI_CHAT')

4. attachFeatureInfo()
   ├─ Purpose: Add helper functions to request
   ├─ Provides: req.isFeatureAvailable(), req.getAvailableFeatures()
   └─ Example: attachFeatureInfo()

5. rateLimitByTier(options)
   ├─ Purpose: Rate limit by subscription tier
   ├─ Returns: 429 when limit exceeded
   └─ Example: rateLimitByTier({ freeLimit: 10, premiumLimit: 100 })

6. adminFeatureOverride()
   ├─ Purpose: Check admin status and set bypass flag
   ├─ Returns: Sets req.adminOverride = true for admins
   └─ Example: adminFeatureOverride()

7. requireFeatureWithOverride(featureName)
   ├─ Purpose: Feature check that respects admin bypass
   ├─ Returns: Bypassed for admins, otherwise enforces
   └─ Example: requireFeatureWithOverride('PREMIUM_FEATURE')

Q: How do I use this with my existing auth?
A: Add feature middleware AFTER your authenticate middleware:
   router.post('/endpoint', authenticate, requireFeature('FEATURE'), handler);

Q: Can I test different tiers locally?
A: Yes! Create users with subscriptionTier = 'FREE' or 'PREMIUM' in tests.

Q: What if a user tier changes mid-session?
A: Feature check uses current req.user.subscriptionTier from auth.
   Token may need refresh if tier changes.

Q: Can I customize error messages?
A: Yes! Edit the response messages directly in feature.middleware.js.

Q: How do I add new features?
A: Add to FEATURES object in /backend/src/config/features.config.js.

Q: Can I use this on public endpoints?
A: Yes! Use trackFeatureUsage() for analytics without blocking.

Q: How do I disable a feature quickly?
A: Set environment variable:
   AI_CHAT_ENABLED=false
