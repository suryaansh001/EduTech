🔧 IMPLEMENTATION DETAILS

How It Works:

1. Check Feature Access
   FeatureGate uses useFeatureFlag() hook
   → Gets user tier from auth context
   → Checks TIER_FEATURES mapping
   → Returns isFeatureEnabled(feature)

2. Render Based on Access
   If feature enabled:
     → Render children
   If feature disabled:
     → Render based on showUpgradeOn mode

3. Handle Callbacks
   When status determined:
     → Call onDeny() if denied
     → Call onFeatureAvailable() if available

4. Track Analytics
   If analytics={true}:
     → Send gtag event with metadata
     → Include tier, feature name, etc.
